# File Explorer freezing in Windows 11

**Category:** Software  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding File Explorer freezing
2. Restarted File Explorer from Task Manager
3. Checked for any connected external or thumb drives
4. Disabled the preview pane in File Explorer
5. Restarted the computer and re-tested performance
6. Closed the ticket with troubleshooting notes
