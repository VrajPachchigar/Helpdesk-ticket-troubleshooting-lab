# Windows 11 search bar not working

**Category:** Software  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding the search bar not working
2. Ended the SearchHost.exe process under Search in Task Manager
3. Checked Indexing Options
4. Restarted the computer
5. Closed the ticket with relevant notes
