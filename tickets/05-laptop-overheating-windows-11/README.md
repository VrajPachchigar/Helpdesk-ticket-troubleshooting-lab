# Laptop overheating (Windows 11)

**Category:** Hardware  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding laptop overheating
2. Checked Task Manager to see whether CPU usage was high
3. Inspected the fans underneath the laptop for cleaning needs
4. Cleaned dust around the fans with a compressed air can
5. Closed the ticket with troubleshooting notes
