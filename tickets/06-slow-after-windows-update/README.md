# Computer slow after Windows update

**Category:** Performance  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding slowness after an update
2. Checked Windows Update status in Settings
3. Restarted the computer
4. Checked background processes in Task Manager
5. Closed the ticket with troubleshooting notes
