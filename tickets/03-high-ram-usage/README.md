# High RAM usage

**Category:** Performance  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding high RAM usage
2. Checked Task Manager to see which app or software was using the most RAM
3. Checked whether the system has enough memory installed
4. Restarted the system to clear temporary memory
5. Closed the ticket with relevant notes
