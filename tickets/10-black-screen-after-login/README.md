# Windows 11 black screen after login

**Category:** Startup  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding a black screen after login
2. Checked startup apps in Task Manager and disabled unnecessary ones
3. Checked background loading activity
4. Checked for pending Windows updates
5. Restarted the machine
6. Closed the ticket with relevant notes
