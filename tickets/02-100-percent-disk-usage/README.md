# 100% disk usage

**Category:** Performance  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks about 100% disk usage
2. Checked disk usage under the Processes tab in Task Manager
3. Checked for pending Windows updates and ran an antivirus scan for malware
4. Deleted unnecessary temporary files
5. Closed the ticket with troubleshooting notes

* Identified the process driving disk usage from the Processes tab in Task Manager
* Installed pending Windows updates, ran an antivirus scan, and deleted temporary files
* Disk usage dropped from **100%** to **20%**
* Ticket closed with troubleshooting notes
