# High CPU usage

**Category:** Performance  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding high CPU usage
2. Checked CPU usage in Task Manager
3. Checked for pending Windows updates
4. Checked system temperature by physically touching the computer

## Result

* Checked CPU usage in Task Manager and identified **[Google Chrome]** as the main consumer
* Checked for pending Windows updates
* Checked system temperature by touching the computer: [warm]
* CPU usage dropped from **60%** to **10%**
* Ticket closed with troubleshooting notes
