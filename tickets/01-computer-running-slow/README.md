# Computer running slow

**Category:** Performance  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks for the slow computer reported by the user
2. Opened Task Manager to find which software or component was causing the sluggishness
3. Closed unnecessary startup apps from Task Manager
