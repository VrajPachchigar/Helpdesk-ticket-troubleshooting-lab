# Windows 11 storage almost full

**Category:** Storage  |  **Ticketing system:** Spiceworks

## Troubleshooting Steps
1. Created a ticket in Spiceworks regarding storage almost full
2. Reviewed storage usage in Windows Settings
3. Cleaned temporary files from Storage settings
4. Removed unnecessary files and apps from the Downloads folder
5. Closed the ticket with troubleshooting notes
