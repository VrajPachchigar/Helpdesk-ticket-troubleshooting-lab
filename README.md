# Troubleshooting Real Computer IT Tickets (Windows 10/11 Help Desk Lab)

A hands-on help desk project where I created and resolved common Windows support tickets in **Spiceworks**, documented the troubleshooting steps for each one, and closed every ticket with resolution notes. Each ticket has its own folder with the steps and screenshots.

## Tools Used

* **Spiceworks** for ticket creation, tracking and closure
* **Windows Task Manager** for process, startup, CPU, RAM and disk analysis
* **Windows Settings** for Windows Update, Storage and Indexing Options
* **File Explorer options** and **antivirus scan**
* **Compressed air** for hardware cleaning
