Troubleshooting Real Computer IT Tickets (Windows 10/11 Help Desk Lab)

A hands-on help desk project where I created and resolved common Windows support tickets in Spiceworks, documenting the troubleshooting steps for each one and closing every ticket with resolution notes.

Goals
Practice the full help desk ticket lifecycle: create → troubleshoot → document → close
Build a repeatable troubleshooting approach for common Windows performance issues
Write clear resolution notes that another technician (or the end user) could follow
Tools Used
Spiceworks – ticket creation, tracking and closure
Windows Task Manager – process, startup, CPU, RAM and disk analysis
Windows Settings – Windows Update, Storage, Indexing Options
File Explorer options – preview pane settings
Antivirus scan – malware check
Compressed air – hardware cleaning (fans / vents)
Tickets at a Glance
#	Issue	Category	Key Fix
1	Computer running slow	Performance	Disabled unnecessary startup apps
2	100% disk usage	Performance	Updates, malware scan, temp file cleanup
3	High RAM usage	Performance	Identified heavy apps, restarted system
4	High CPU usage	Performance	Checked Task Manager, updates, temperature
5	Laptop overheating (Windows 11)	Hardware	Cleaned dust from fans
6	Slow after Windows update	Performance	Verified update status, restart, background processes
7	Storage almost full (Windows 11)	Storage	Temp files and unused files/apps removed
8	File Explorer freezing	Software	Restarted Explorer, disabled preview pane
9	Search bar not working	Software	Ended SearchHost.exe, checked indexing
10	Black screen after login	Startup	Disabled startup apps, updates, restart
Ticket Details
1. Computer running slow
Created a ticket in Spiceworks for the slow computer reported by the user
Opened Task Manager to find which software or component was causing the sluggishness
Closed unnecessary startup apps from Task Manager
2. 100% disk usage
Created a ticket in Spiceworks about 100% disk usage
Checked disk usage under the Processes tab in Task Manager
Checked for pending Windows updates and ran an antivirus scan for malware
Deleted unnecessary temporary files
Closed the ticket with troubleshooting notes
3. High RAM usage
Created a ticket in Spiceworks regarding high RAM usage
Checked Task Manager to see which app or software was using the most RAM
Checked whether the system has enough memory installed
Restarted the system to clear temporary memory
Closed the ticket with relevant notes
4. High CPU usage
Created a ticket in Spiceworks regarding high CPU usage
Checked CPU usage in Task Manager
Checked for pending Windows updates
Checked system temperature by physically touching the computer
5. Laptop overheating (Windows 11)
Created a ticket in Spiceworks regarding laptop overheating
Checked Task Manager to see whether CPU usage was high
Inspected the fans underneath the laptop for cleaning needs
Cleaned dust around the fans with a compressed air can
Closed the ticket with troubleshooting notes
6. Computer slow after Windows update
Created a ticket in Spiceworks regarding slowness after an update
Checked Windows Update status in Settings
Restarted the computer
Checked background processes in Task Manager
Closed the ticket with troubleshooting notes
7. Windows 11 storage almost full
Created a ticket in Spiceworks regarding storage almost full
Reviewed storage usage in Windows Settings
Cleaned temporary files from Storage settings
Removed unnecessary files and apps from the Downloads folder
Closed the ticket with troubleshooting notes
8. File Explorer freezing in Windows 11
Created a ticket in Spiceworks regarding File Explorer freezing
Restarted File Explorer from Task Manager
Checked for any connected external or thumb drives
Disabled the preview pane in File Explorer
Restarted the computer and re-tested performance
Closed the ticket with troubleshooting notes
9. Windows 11 search bar not working
Created a ticket in Spiceworks regarding the search bar not working
Ended the SearchHost.exe process under Search in Task Manager
Checked Indexing Options
Restarted the computer
Closed the ticket with relevant notes
10. Windows 11 black screen after login
Created a ticket in Spiceworks regarding a black screen after login
Checked startup apps in Task Manager and disabled unnecessary ones
Checked background loading activity
Checked for pending Windows updates
Restarted the machine
Closed the ticket with relevant notes
